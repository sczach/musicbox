Composition Guide
Workflow Tips
Sparse Patterns

32–64 step patterns with 2–4 active trigs per track. At 70 BPM a 64-step pattern is ~27 seconds — an event, not a loop.

Parameter Locks

Hold any trig and turn a knob. Lock filter, reverb send, or sample start per step. The primary tool for making patterns feel alive.

Conditional Trigs

Hold trig + right arrow. 1:2 fires every other loop, 1:4 every fourth. Simple patterns that never repeat.

Copy → Paste → Vary

FUNC+COPY, move to next slot, FUNC+PASTE, edit 1–2 trigs. Keeps musical continuity.

Euclidean Rhythms

E(3,8), E(5,13), E(7,16) distribute pulses evenly. Use the Euclidean Generator in any track editor.

LFO Breathing Pads

LFO → FLTR CUTOFF, slow triangle, speed 1–4. Filter breathes independently — living pad, zero extra trigs.

FX Send Automation

P-lock SEND: step 1 dry, step 33 drenched. Same hit sounds completely different.

Pro 3 Integration

Track 16 as MIDI out, ch 1, to gate the Pro 3. Chord mode sends full chords.

How Composition is Generated

Rhythm Generation Rules

Each track is classified by role (kick, snare, hat, bass, harmonic, melody, texture, percussion, MIDI). Each role has a pulse range and pattern length appropriate for the genre.

Step patterns are generated using the Euclidean / Bjorklund algorithm: given k pulses distributed across n steps, the algorithm spaces them as evenly as possible. This mirrors how natural rhythm patterns emerge in African, Latin, and electronic music traditions.

A random rotation offset shifts the pattern start point. Small offsets produce subtle groove variation; larger offsets create a completely different rhythmic feel.

Harmonic Generation Rules

Key recommendations are drawn from a curated set of modes and scales matched to the genre's emotional character:

  • Ambient / Dark Ambient → Natural Minor (Aeolian), Dorian, Phrygian — modal and introspective
  • Techno / DnB / IDM → Phrygian, Locrian, Chromatic — dark and tense
  • House / Downtempo → Dorian, Natural Minor, Major — soulful and emotional
  • Trap / Jungle → Minor Pentatonic, Natural Minor — accessible and direct
P-Lock Melody System (Digitakt)

The Tune parameter on Digitakt adjusts sample pitch in semitones. To build a melody via p-locks: tune your sample to the root note, then lock Tune values per step.

Example — sample tuned to A, Natural Minor scale:

A (root)
+2
B (maj2)

+10

+12

The same principle applies to any root — the intervals are always relative to wherever your sample is tuned.

What Regenerate Does NOT Do

It does not generate melody sequences — it generates rhythm patterns for melodic tracks and tells you which pitches to p-lock. You decide the actual note order. The tool gives you the rhythmic skeleton and harmonic palette; you provide the musical intention.
